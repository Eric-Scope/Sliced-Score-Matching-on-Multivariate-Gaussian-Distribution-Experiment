This experiment benchmarks the performance of the sliced score matching with variance reduction objective on learning the score of a multivariate Gaussian distribution equipped with a distance based covariance matrix. The purpose of this experiment is to recreate the suspected high frequency error structure present in latent space of an autoencoder employed on quantitative photo-acoustic computed tomography (qPACT) breast imaging problems [(Crafts, 2026)](https://arxiv.org/abs/2610.03956) in the more general setting of a multivariate Gaussian distribution. We aim to provide rigorous analysis of this error structure present in score matching through its recreation and evaluation using Fourier analysis, and later implement the recent discovery of sliced score matching in Bochner spaces to minimize these errors. This project is currently a work in progress.
